# Support

## How to get help

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/ale94lko/al-maidah/issues/new/choose).
- **Questions about the MVP plan:** comment on [issue #1](https://github.com/ale94lko/al-maidah/issues/1).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not file a public issue.

## What to include

- What you expected to happen
- What actually happened
- Steps to reproduce
- Environment details (OS, Node version, browser) when relevant

## Response

This project is maintained in public on a best-effort basis. Security reports follow the timelines in `SECURITY.md`.
